# 更新日志

## 1.14.3

- 修复：Android 8～12 导入 GPX 线路文件时崩溃（读取流用了 API 33 才有的方法），已改为兼容实现
- 修复：Android 8.0 / 8.1 打开运动伴侣图片时可能崩溃（动画图片类自 API 28 才有），已按系统版本隔离

## 1.14.2

- 修复：进程被杀/崩溃后，系统定位可能被「模拟位置」长期顶掉（打车/共享位置/相机位置异常）；重新打开应用或开机后自动恢复
- 修复：模拟位置授权被撤销时程序每秒抛异常并反复弹提示；现在立即进入挂起态，权限恢复后 15 秒内自动续注入
- 优化：注入节奏与引擎心跳解耦，默认 1Hz（接近真机 GPS 节奏），进度条与摇杆手感不受影响
- 优化：注入时间戳改为单调递增并检测时钟跳变，避免目标 App 判定「定位数据异常」
- 优化：不再伪造网络定位结果，只提供一个明显偏旧的低精度兜底，减少第三方 App 的「GPS 信号弱 / 非 GPS 定位」误判
- 优化：GNSS extras 补齐 satellites / meanCn0 / maxCn0，水平精度改为缓慢游走，去掉固定精度特征

## 1.14.1

- 修复：注入服务被系统回收并重连后，新旧引擎并存导致通知进度抖动
- 修复：服务被系统回收时，本次跑动记录可能丢失
- 修复：超长距离（全马级别）锁屏后引擎停摆，WakeLock 改为滑动续期
- 修复：退化轨迹上「临时插点」可能注入无效坐标
- 修复：悬浮胶囊手动接管收尾回调与展开动画的残留
- 升级 targetSdk 至 34：前台服务合规加固，开跑前自动引导授予定位权限
- GPX 导入增加 10MB 上限，超大文件不再卡死界面
- 运行日志迁移到内部存储，显式禁用明文流量
- 清退约 2300 行旧版遗留代码（旧摇杆/旧历史页/旧设置页），启动更轻
- 构建体系现代化：依赖版本统一管理，开启并行构建
- 设置页「支持云迹」上移到偏好分组下方
