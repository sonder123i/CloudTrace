# CloudTrace v1.14.3

## 修复

- Android 8.0～12 导入 GPX 线路文件时崩溃：读取文件流用了 API 33 才提供的方法，未开启 desugaring 时调不到就会抛 `NoSuchMethodError`。已换成兼容实现，超限判断行为不变。
- Android 8.0 / 8.1 打开运动伴侣图片时可能崩溃：代码里引用的动画图片类自 API 28 才有，在 API 27 上解析类会失败。已按系统版本隔离，旧系统走静态图路径。

## 说明

- 本版本只包含上述修复，不改变注入、巡航与位置策略；从 1.14.2 升级可直接覆盖安装。
- 若此前在 Android 8～12 上一直没导入过 GPX，本次升级无感知差异。

## 校验

- 版本：1.14.3 (1143)
- 安装包：CloudTrace_1.14.3_arm64-v8a_release.apk
